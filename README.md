# Day3

## フォルダ構成

```
day03/
├── 辞書型/
├── ブール演算と集合/
└── 関数/
    ├── solution/   … 教材参考スクリプト
    ├── exercises/  … 演習問題
    └── extra/      … 追加問題（任意）
```

## 進め方

1. 各トピックの `solution` を実行し、行末の `→` と出力を照合する
2. 同じ番号の `exercises` にコードを書く
3. 余力があれば `extra` に挑戦する

## 実行例

```bash
python training/day03/辞書型/solution/01_辞書の基本.py
python training/day03/辞書型/exercises/01_辞書の基本.py
```
