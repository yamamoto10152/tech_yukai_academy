# Day2 AM

## フォルダ構成

```
day02_am/
├── 四則演算と変数/
│   ├── solution/
│   ├── example/
│   └── extra/
├── リストとタプル/
│   ├── solution/
│   ├── example/
│   └── extra/
└── 文字列と入力値変換/
    ├── solution/
    ├── example/
    └── extra/
```

## 進め方

1. 各トピックの `solution` を実行し、行末の `→` と出力を照合する
2. 同じ番号の `example` に、コメントの指示どおりコードを書く
3. 余力があれば `extra` に挑戦する

## 実行例

```bash
python training/day02_am/文字列と入力値変換/solution/01_文字列の基本.py
python training/day02_am/文字列と入力値変換/example/01_文字列の基本.py
```
