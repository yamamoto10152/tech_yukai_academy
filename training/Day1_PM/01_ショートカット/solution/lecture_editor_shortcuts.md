# Day1 午後レクチャー: コメントアウトと Cursor のショートカット

Python の文法上のコメントは **`#` から行末まで** です。複数行を止めたいときは、**各行に `#`** を付けるか、Cursor の **一括トグル** を使います。

この資料は **Windows** 上の **Cursor** を想定しています。キーバインドを変更している場合は、**ファイル → 設定 → キーボード ショートカット**（または **Ctrl + K** のあと **Ctrl + S**）で実際の割り当てを確認してください。

---

## 1. コメントアウト（行の無効化・説明）

| やりたいこと | 手動 | Cursor（既定の例） |
|-------------|------|---------------------|
| 1行コメント | 行頭に `#` | カーソル行で **Ctrl + /** |
| 複数行をまとめてコメント | 各行に `#` | 複数行選択 → **Ctrl + /** |
| ブロックコメント | Python に `/* */` 型の公式構文はない | **Shift + Alt + A**（言語により挿入される記号が違う。Python では `#` 行の方が無難なことが多い） |

**注意（Python）**

- `""" ... """` は厳密には **文字列** です。モジュール・クラス・関数の直後に置くものは **docstring** としてツールが解釈します。
- 「動かないようにしたいだけ」なら、基本は **`#` ( Ctrl + / )** が安全です。

---

## 2. Python 開発でよく使うショートカット（Cursor・Windows・一般的な既定）

| 操作 | ショートカット（例） |
|------|----------------------|
| コマンドパレット | **Ctrl + Shift + P** |
| クイックオープン（ファイルへジャンプ） | **Ctrl + P** |
| 統合ターミナルの表示切替 | **Ctrl + `**（バッククォート） |
| ターミナルで Python を実行 | ターミナルで `py ファイル名.py` または `python ファイル名.py` |
| 整形（Formatter が有効な場合） | **Shift + Alt + F** |
| 定義へ移動 | **F12** または **Ctrl + クリック** |
| 参照を検索 | **Shift + F12** |
| ファイル内検索 | **Ctrl + F** |
| ワークスペース検索 | **Ctrl + Shift + F** |
| サイドバー表示切替 | **Ctrl + B** |
| 行の複製 | **Shift + Alt + ↓** |
| 行の移動 | **Alt + ↑ / ↓** |
| エージェント / チャットを開く（Cursor） | **Ctrl + L**（環境・設定で異なる場合あり） |
| Composer を開く（Cursor） | **Ctrl + I**（環境・設定で異なる場合あり） |

**補足**

- 「Python 言語のショートカット」というより、**エディタ（Cursor）のショートカット**で作業効率が大きく変わります。
- キーが思い出せないときは **コマンドパレット**（**Ctrl + Shift + P**）で「Toggle Line Comment」「Format Document」「Python: Run」と検索すると、現在の割り当てが確認できます。
